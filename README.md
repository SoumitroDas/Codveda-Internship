# Codveda Internship: NB.1.8.1 Variant Analysis
## Overview
Processed WHO data for NB.1.8.1 variant across 5 tasks: data collection, cleaning, analysis, visualization, and reporting.

## Tasks
- *Task 1: Data Collection*: Extracted NB.1.8.1 data from CSVs.
- *Task 2: Data Cleaning*: Formatted prevalence, mutations, and handled missing data.
- *Task 3: Data Analysis*: Analyzed prevalence trends (328% increase) and regional growth.
- *Task 4: Data Visualization*: Created prevalence and regional growth plots.
- *Task 5: Reporting*: Summarized findings in CSV and text reports.

## Files
- *Input*: nb_1_8_1_variant_data.csv, nb_1_8_1_detailed_summary.csv
- *Scripts*: merge_nb181_data.py, clean_nb181_data.py, analyze_nb181_data.py, visualize_nb181_data.py, report_nb181_data.py
- *Outputs*: nb181_data_2025.csv, nb181_data_2025_cleaned_new.csv, nb181_analysis_2025.csv, nb181_prevalence_plot.png, nb181_regional_growth_plot.png, nb181_report_2025.csv, nb181_report_2025.txt

## Challenges
- Overcame PDF parsing issues by using CSVs.
- Handled permission errors and Pandas warnings.
